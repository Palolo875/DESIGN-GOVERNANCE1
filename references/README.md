# Références — aides de la skill

Ces quatre fichiers accompagnent la [skill](../SKILL.md) : ils aident l’agent à suivre la séquence et à transporter une trace, sans créer de règle. Les sections propriétaires font foi ; ces pages s’y réfèrent.

| Fichier | Contenu |
|---|---|
| [`examples.md`](examples.md) | Exemples de runs par mode, avec leur trace ; illustratifs, à reprendre pour la séquence et non pour le style |
| [`flow.md`](flow.md) | Flux de décision d’un travail, de la demande à la clôture, et rendez-vous de lecture |
| [`canonical_minimum.md`](canonical_minimum.md) | Aide-mémoire minimal des séparations à ne jamais fusionner quand les sources ne sont pas disponibles |
| [`machine_projection.md`](machine_projection.md) | Projection machine de la trace pour le transport entre agents ou scripts, et son lien avec la `RUN_CARD` |

Pour la suite : les [chemins de l’agent](../agent/README.md) disent quoi lire selon le mode ; la [gouvernance](../gouvernance/README.md) décrit preuves, limites et clôture.
