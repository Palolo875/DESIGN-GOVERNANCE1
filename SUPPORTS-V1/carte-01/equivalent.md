V1.0.0 expérimentale. Proposition de support, dérivée du produit `4e1f9cc20a9887d570a720934ca5b1752c78971a`.

Carte de responsabilités, pas un ordre fixe d’exécution.

## Entrées

- **Je découvre** : [Ouvrir le guide pour commencer](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/guides/commencer.md). Le guide pour commencer explique quoi demander, quoi fournir, ce que vous recevez et comment poursuivre.
- **Je conçois** : [Ouvrir le guide du designer](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/guides/designer.md). Le guide du designer relie les sujets, leurs combinaisons et les gestes de fabrication.
- **Je travaille en équipe** : [Ouvrir le guide d’équipe](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/guides/equipe.md). Le guide d’équipe relie le pilotage, les preuves, la trace et la livraison, selon les besoins du travail.
- **Je relis ou je décide** : [Ouvrir la gouvernance](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/gouvernance/README.md). La gouvernance aide à vérifier les affirmations, protéger les risques et préparer une clôture ou une acceptation.
- **Je suis un agent** : [Ouvrir la skill](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/agent/skill/SKILL.md). La skill active le classement et les lectures utiles. Les sections propriétaires restent la source de la règle.
- **Je maintiens le système** : [Ouvrir la maintenance](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/maintenance/README.md). La maintenance rassemble l’évolution, la validation et la préparation des versions.

- **Direction** : Choisir un point de vue situé. [direction/](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/design/direction/diriger.md).

- **Formes** : Composer une structure adaptée. [formes/](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/design/formes/README.md).
- **Produit** : Construire, observer et finir. [produit/](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/design/produit/README.md).
Source : [design/](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/design/README.md).

### Gouvernance — éprouver

Protéger un risque, vérifier, garder une trace. L’effort suit la décision et les besoins de reprise.


Trace complète pour un travail persistant, partagé, audité ou à accepter. Les preuves applicables restent dues. Risque critique : protéger avant le choix concerné.

Source : [gouvernance/](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/gouvernance/README.md).

### Maintenance — entretenir

Versions, validation et distributions. Faire évoluer l’ensemble.

Source : [maintenance/](https://github.com/Palolo875/DESIGN-GOVERNANCE1/blob/4e1f9cc20a9887d570a720934ca5b1752c78971a/maintenance/README.md).

## Relations

- Guides → Design : orienter.
- Agent → Design : lire et fabriquer.
- Design ↔ Gouvernance : risque · décision · reprise.

La maintenance entretient toutes les parties ; elle ne désigne pas une dernière étape.
