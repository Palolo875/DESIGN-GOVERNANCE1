# Design Governance — suivi de l'outil de jugement esthétique

Branche de travail, hors paquet : elle ne contient pas le système, seulement l'étude qui l'observe.

| Fichier | Rôle |
|---|---|
| `plan-de-suivi-outil-esthetique.md` | Objectif, décisions, étapes et journal de suivi |
| `protocole-etat-de-reference.md` | Méthode de l'état de référence (étape 4) et son journal |
| `confrontation-systeme-recherches.md` | Le système confronté aux recherches sur la qualité visuelle : constats, verdicts, mobilisation observée, propositions et suite donnée |
| `confrontation-v2.md` | La même confrontation sur la révision suivante, éclairée par le run 7 : écarts fermés, écarts ouverts, propositions T1 à T7 |
| `references-visuelles-et-plan.md` | Lecture de quatre séries de références visuelles et inventaire des propositions, par étape |
| `etat-de-reference/` | Briefs, caractères attendus, productions mesurées, dossier d'évaluation à l'aveugle |
| `outils/` | Scripts de traitement des productions et de construction du dossier d'évaluation |

Les mesures emploient les scripts du paquet (`check_render.py`, `check_caractere.py`, `journal_mobilisation.py`) de la branche `claude/friendly-albattani-tl6cvw`.
