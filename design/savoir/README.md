# Savoir — le livre de référence

Le savoir de design, par sujet. Chaque fichier se lit seul ; le lecteur sert aussi chaque section par son adresse (`python3 scripts/read_route.py savoir/couleur`).

| Fichier | Sujet |
|---|---|
| [`fondements.md`](fondements.md) | Principe fondateur, compromis, cadrage du contexte |
| [`qualite-creative.md`](qualite-creative.md) | Ambition, forme située, registres, composition, émotion, premier contact, couleur |
| [`typographie.md`](typographie.md) | Typographie et données |
| [`composition.md`](composition.md) | Jugement visuel, vocabulaire perceptuel, états |
| [`images-et-sources.md`](images-et-sources.md) | Ancre, sourcing visuel, familles visuelles |
| [`styles.md`](styles.md) | Profils de style et réglages |
| [`systeme-de-design.md`](systeme-de-design.md) | Tokens et composants |
| [`contexte.md`](contexte.md) | Accessibilité, contextes à fort enjeu, responsive, mouvement |
| [`techniques.md`](techniques.md) | Techniques, tests et production par médium |
| [`gout-et-tendances.md`](gout-et-tendances.md) | Goût, références, tendances datées, ressources |
| [`connexions.md`](connexions.md) | Quand plusieurs domaines se croisent |

Trois parties attendent encore leur place : la façon de lire ce savoir, les règles d’or et l’intégrité. Elles sont dans `V1/official/SAVOIR.md`.
