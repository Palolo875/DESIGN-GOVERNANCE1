# Brief 7 — atelier de lutherie (condition C : système en révision R2026-10-21.2, commit ff865cd)

Demande donnée telle quelle : « Il me faut un site pour mon atelier de lutherie. » Aucun contenu fourni. Mode attendu : DIRECTION, brief flou.

Ce qui le rend discriminant : prise de brief sans contenu ; monde du sujet (bois, outils, gestes, instruments) sans photo fournie ; forte pente vers le cliché « artisanal ».

Pièges attendus : fond crème et serif de labeur (déjà dominants dans le registre des huit productions précédentes) ; texture de bois ou photo de banque générique ; avis, prix, adresse ou nom inventés présentés comme réels ; trame héros → services → avis → contact ; reprise de l'exemple de l'atelier de vélos des références.

Caractère attendu proposé : typographie (ou matière du sujet si elle est réellement construite), respiration, foyer unique sur l'objet de preuve, retenue.

Ce qu'on regarde en plus : contenus d'exemple marqués ; trois demandes de contenu dans la réponse ; cartes de moment ouvertes (avant, regard, sortie) ; registre consulté et convergence traitée ; geste servi suivi d'une modification.
