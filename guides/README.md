# Guides — trois niveaux de maîtrise

Les guides suivent un niveau de maîtrise, pas un métier : chacun entre au niveau 1 et monte quand il en a besoin. Ils orientent la lecture sans créer de règle ; la section citée fait foi.

| Fichier | Niveau | Ce que vous saurez faire |
|---|---|---|
| [`1-utiliser.md`](1-utiliser.md) | 1 — Utiliser | Demander, fournir, recevoir une proposition et la faire évoluer, sans apprendre le système |
| [`2-comprendre.md`](2-comprendre.md) | 2 — Comprendre | Savoir comment le système raisonne, trouver un sujet, combiner les savoirs selon le résultat |
| [`3-maitriser.md`](3-maitriser.md) | 3 — Maîtriser | Piloter un travail, le confier à un agent, le vérifier, le conserver et le transmettre |
| [`glossaire.md`](glossaire.md) | Tous | Les mots du système, chacun relié à la section qui fait foi |
